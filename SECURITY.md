# Security policy

## Supported versions

Security fixes are applied to the latest published OCTview3R release. This is
research software and must not be treated as a medical device or used for
clinical decision-making.

## Reporting a vulnerability

Please do not publish an exploitable vulnerability or sensitive sample data
in a public issue. Report it privately to the repository owner through
GitHub's private vulnerability reporting feature. Include the affected
version, input format, reproduction steps, and potential impact.
